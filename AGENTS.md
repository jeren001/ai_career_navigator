## Developer Responsibilities

- I am exclusively responsible for frontend development.
- My project partner is responsible for backend development.
- My working branch is `frontend`.
- My primary working directory is `frontend/`.

## Development Restrictions

- Never modify backend files.
- Never modify my partner's branch.
- Never modify the `main` branch.
- Never implement server-side business logic without discussing it with me.
- Never expose API keys in frontend code.
- When a feature requires backend functionality, explain the requirements and propose an API contract for my partner.
- Clearly distinguish mock functionality from real backend integrations.
- Preserve existing project architecture and design conventions.

## Approval Workflow

- Discuss functionality and design before implementation.
- Implement only approved changes.
- Run relevant automated tests.
- Wait for my personal visual and functional testing.
- Never commit without my explicit approval.
- Never push to GitHub before my personal testing and explicit authorization.
- Never merge, rebase, force push or switch branches without permission.
