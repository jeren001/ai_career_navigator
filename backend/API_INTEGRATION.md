# Frontend API integration

Use the operation schemas at `/api-docs/openapi.json`. In development, `/api-docs` exposes the same contract in Swagger UI. Unless a route is public or explicitly accepts a guest, send the registered account's `Authorization: Bearer <access_token>` header.

| Module | Backend operations | Integration state |
| --- | --- | --- |
| Authentication | `POST /api/auth/{guest,register,login,transfer}`, `GET /api/auth/me`, email verification and change, password reset and change, `DELETE /api/auth/account` | Guest registration keeps the original user ID. Transfer moves completed assessments to an existing account. Change and reset invalidate existing sessions. Account mail requires the configured email service. Sign-out clears the client token. |
| Profile and Settings | `GET/PATCH /api/profile`, `GET/PUT/DELETE /api/profile/photo`, `GET /api/profile/public/{username}` and its `/photo`, `GET/PATCH /api/settings`, `GET /api/notifications`, `PATCH /api/notifications/{id}/read` | PostgreSQL stores account preferences, profiles, photos and notification state. Photo uploads require ImageMagick 7. In-app delivery covers assessment and roadmap events. Job alerts, learning reminders, platform updates and optional notification email are preferences only. |
| Dashboard | `GET /api/dashboard` | Returns account statistics, current assessment and roadmap progress, saved career recommendations, and up to 10 recent events. |
| Career catalog | `GET /api/careers`, `GET /api/careers/{id}` | Public. List returns an array, detail returns a role object. Match filters against original catalog labels. Use `market_pulse.translations["zh-CN"]` for display after applying `seed-expansion.sql`. |
| Career Test | `POST /api/assessment/{start,answer,evaluate}` and `GET /api/assessment/drafts`, `GET /api/assessment/history` and `GET /api/assessment/{id}`. The same operations are available under `/api/quiz`. | PostgreSQL stores drafts and completed results. Owners can resume on any server instance. |
| My Skills | `GET/POST /api/skills`, `PATCH/DELETE /api/skills/{id}`, `POST /api/skills/compare` | The structured inventory persists independently of the profile's legacy skills list. A trusted backend workflow can record practical ratings. Challenge completion itself does not award a proficiency rating. |
| AI Career Match | `GET /api/career-match`, `POST /api/career-match/refresh` | The authenticated owner can read the latest completed assessment, including a guest. Refresh requires an account. GET uses stored results and current skill gaps with zero AI attempts. |
| My Roadmap | `GET/POST /api/roadmaps`, `GET/PATCH/DELETE /api/roadmaps/{id}`, `PATCH /api/roadmaps/{id}/milestones/{milestoneId}` | Archiving preserves milestones. Deletion removes the roadmap and milestones. |
| My Resume | `GET/POST /api/resumes`, `POST /api/resumes/upload`, `GET/PATCH/DELETE /api/resumes/{id}`, `GET /api/resumes/{id}/file`, `POST /api/resumes/{id}/analyze` | Structured data and original files persist. Analysis returns guidance for the request. Upload is a raw PDF or DOCX body up to 5 MiB. Extraction needs Python and Poppler for PDF. |
| Learning Hub | `GET /api/learning/resources`, `GET /api/learning/progress`, `PATCH /api/learning/progress/{resourceId}`, plus challenge discovery and submission APIs | Catalog discovery is public. Accounts can save resource bookmarks and report completion. |
| Interview Simulator | `GET/POST /api/interviews`, `GET /api/interviews/{id}`, `POST /api/interviews/{id}/{answers,evaluate}` | Sessions, answers and evaluations persist. Evaluation can return 202 with the current session. Poll the session while processing. |
| Job and Internship Finder | No backend routes | Vacancy search requires authorized providers. The `origin/backend-jobs` ref contains a provider research plan. |
| AI Assistant | `GET/POST /api/career-assistant/conversations`, `GET/PATCH/DELETE /api/career-assistant/conversations/{id}`, `POST /api/career-assistant/conversations/{id}/messages`, `PUT /api/career-assistant/conversations/{id}/messages/{turnNumber}/bookmark`, `GET /api/career-assistant/bookmarks` | Conversations, titles, pins, and response bookmarks persist. |
| Support | No backend routes | Ticket intake, status and delivery require a defined support workflow and destination. |

Successful response shapes vary by operation. Catalog lists can return a bare array. Account data is wrapped as `user`, `profile` or `settings` according to the route. Paginated list responses use named arrays with `next_offset` or `next_before`. A 204 response has no body. Photo and original résumé downloads are binary. The shared error response is `{ "error": "English message" }`. Translate errors in the client using HTTP status and operation context. Handle `Retry-After` on rate-limited operations.

Use `en` and `zh-CN` for APIs with a language option. Assessment questions, recommendations, interviews, Assistant replies and supported catalog text use localized content. Resource display language and the provider's learning language are independent. Identifiers, field names, and catalog filter values stay stable across locales.

## Personal progress contracts

- **Career Test.** Send the owner token, including a guest token, to list or resume drafts. `GET /api/assessment/drafts` lists the 20 most recently updated drafts. `GET /api/assessment/{id}` returns the current question or the completed result. After a 409 or a lost response, reload this route before retrying an answer. A process failure during scoring may leave an answer claim active for up to two minutes. `GET /api/assessment/history?before=<session_id>` returns up to 20 completed results in descending session ID order. Pass `next_before` to load another page. Results created before migration 015 can have a null `assessment_id` and only the available saved fields. Drafts created in memory before 015 cannot be recovered. Guest registration preserves drafts. Guest transfer to an existing account continues to move completed assessments only.
- **Dashboard.** `GET /api/dashboard?language=zh-CN` returns `statistics`, `progress`, `recommendations`, and `recent_activity`. Omit the locale to use the account preference. The recommendation section shows up to three saved professions in the assessment's language. Active roadmap and draft progress can be null. Recent activity is derived from existing records and is limited to 10 events. These reads make zero AI requests.
- **AI Assistant.** Create with an optional `title` or patch `{"title":"学习规划","pinned":true}` on the conversation. A null title clears it. Pinned conversations appear first. Metadata changes preserve the message revision. PUT `{"bookmarked":true}` on a turn's bookmark route to save its assistant response and use false to clear it. The bookmark list supports `limit` and `offset`. Deleting a conversation also removes its bookmarks.
- **My Roadmap.** PATCH `{"archived":true}` on the roadmap or send false to restore it. The patch returns `{ "roadmap": { "id": "...", "archived_at": "..." } }` with a null timestamp for active plans. Lists default to active and accept `status=archived` or `status=all`. Archived plans remain readable by ID and are excluded from the dashboard's active progress. DELETE returns 204 and permanently removes the plan and its milestones.
- **Learning Hub.** PATCH `{"bookmarked":true,"completed":true}` on a catalog resource's progress route. Send either field independently and use false to clear it. GET returns `{ language, progress }` and accepts `status=all|bookmarked|completed` and `language=en|zh-CN`. It defaults to the account locale. Completion is self-reported and does not award a credential.

## Database migration compatibility

Start with `database/schema.sql`, then apply `database/seed.sql` and `database/seed-expansion.sql` for a new database. From `backend`, run `npm run migrate` against both fresh databases and databases previously used by `frontend-integration`.

The older branch's `010_career_assistant.sql` and the backend's `008_career_assistant.sql` create the same tables and index. The backend migration tolerates the existing objects, so an upgrade keeps saved turns and applies `011_career_assistant_turn_claim.sql` and subsequent migrations. A database may retain both filenames in `schema_migrations`. `010_configurable_guest_ai_budget.sql` is a separate migration. The backend runs pending migrations and records their filenames in one transaction under a PostgreSQL advisory lock.

Migration `015_personal_progress.sql` adds draft and learning progress tables, optional result snapshots for existing assessment history, and optional title, pin, bookmark and archive fields. It preserves existing rows.

Run `RUN_SKILLS_POSTGRES_TEST=1 npm test` on a disposable, migrated and seeded PostgreSQL database to include ownership, persistence, concurrency and localization coverage. Configure `DOTENV_CONFIG_PATH=/dev/null` and an explicit `DATABASE_URL` to target the disposable database.
